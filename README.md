# 🔬 ChemistryOnLoop: Computational Cosmetic Toxicology & Formulation Auditor

An open-source chemical informatics web application engineered to parse complex cosmetic ingredient matrices and screen for toxicological risks, allergens, and formulation thresholds. 

## 🎯 Project Overview
ChemistryOnLoop bridges the gap between Computer Science and Chemical Engineering. Developed independently as a Class 11 student in India, this tool addresses the lack of ingredient transparency in affordable consumer cosmetics by democratizing molecular safety data for everyday users.

## ⚙️ Core Technical Features
- **Deterministic String Parsing:** Efficiently processes multi-ingredient text blocks (separated by commas) to audit whole product matrices instantly.
- **Toxicological Classification Back-End:** Maps parsed chemical strings against verified consumer safety frameworks (including EWG and CIR data guidelines).
- **Interactive Data Visualization:** Implements Streamlit's reactive UI architecture for immediate, color-coded risk assessment and mechanism explainers.

## 🛠️ Technology Stack
- **Language:** Python 3.x
- **Framework:** Streamlit (Core UI & State Management)
- **Deployment:** Streamlit Community Cloud
